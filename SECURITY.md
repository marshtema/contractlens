# Политика безопасности

## Поддерживаемые версии

В разработке поддерживается только `main`. Релизы тегируются по semver когда выйдет 1.0.

## Сообщить об уязвимости

Если нашли уязвимость — **не открывайте публичный issue**. Напишите на:

📧 **security@contractlens.ai**

Ответим в течение 48 часов. Раскрытие — после фикса (responsible disclosure).

## Что считается уязвимостью

- Утечка чужих документов / сессий
- Bypass лимитов плана
- Bypass auth / cookie injection
- XSS / SSRF / RCE
- Утечка API-ключей в логи или ответы

## Что НЕ считается уязвимостью

- Rate limit обхода через rotate IP (мы не претендуем на anti-DDoS)
- Stripe sandbox-функционал
- Mock-режим возвращает «слабые» ответы (это by design)
